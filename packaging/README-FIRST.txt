EDEN VIDEO  -  A Professional Video Editing Software
=====================================================

Nothing to install. Everything Eden needs is inside this folder.

WINDOWS   Double-click  eden-video.exe
          If Windows says "protected your PC": click "More info", then "Run anyway".
          (Eden is not code-signed, so Windows shows this once.)

MAC       Right-click  "Start EDEN VIDEO.command"  ->  Open  ->  Open.
          (Do this once. It lets macOS run Eden, then starts it.)

LINUX     Open a terminal in this folder and run:   ./eden-video

Eden opens in your web browser at http://localhost:8000
Keep the black window open while you use Eden. Close it (or press Ctrl+C) to stop.

Your videos and settings are saved in the "data" folder next to this file.
To see if anything is wrong, run:  eden-video doctor

Useful options:  --lan (use Eden from your phone on the same Wi-Fi)   --port 9000   --no-browser
